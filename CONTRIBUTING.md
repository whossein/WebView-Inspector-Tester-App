# Contributing to PWA Inspector & Test

First off, thank you for considering contributing to **PWA Inspector & Test**! It's people like you that make such tools better for the entire developer community.

## 🐞 Reporting Bugs

If you find a bug, please create an issue on GitHub and include:
*   Your device model and Android version.
*   Steps to reproduce the bug.
*   Expected behavior vs. actual behavior.
*   Screenshots or screen recordings (if applicable).

## 💡 Suggesting Enhancements

Have a great idea for a new feature or an improvement? We'd love to hear it!
*   Check existing issues to make sure your idea hasn't been proposed yet.
*   Open a new issue describing the feature, why it would be useful, and how you imagine it working.

## 💻 Pull Requests (Code Contributions)

If you'd like to write code to fix a bug or add a feature, please follow these steps:

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally.
3.  **Create a new branch** for your feature or bug fix:
    ```bash
    git checkout -b feature/your-feature-name
    # or
    git checkout -b fix/your-bug-fix
    ```
4.  **Make your changes**. Please ensure your code follows the existing style:
    *   Use **Kotlin** and **Jetpack Compose**.
    *   Keep your code clean, readable, and well-documented.
    *   Follow standard Android architecture guidelines (MVVM).
5.  **Test your changes** thoroughly on an emulator or physical device.
6.  **Commit your changes** with clear and descriptive commit messages.
7.  **Push your branch** to your fork:
    ```bash
    git push origin your-branch-name
    ```
8.  **Submit a Pull Request** (PR) to the main repository. Include a clear description of what your PR does and link to any relevant issues.

## 🏗️ Development Environment

*   Use the latest stable version of **Android Studio**.
*   Ensure you format your Kotlin code properly before committing.
*   Avoid committing unnecessary files (e.g., local configuration files).

## 📜 Code of Conduct

Please be respectful and constructive when interacting with other contributors. We want to build a welcoming and collaborative environment.

Thank you for your help in making this app awesome! ❤️
